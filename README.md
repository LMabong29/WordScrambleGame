# 🧠 Word Scramble Game

Welcome to the **Word Scramble Game**, a fun and interactive browser-based game that challenges your vocabulary and speed! 🔤⏱️

## 🎮 Features

- 🔀 Randomized letter shuffling
- ⏰ Timed rounds with progressive difficulty
- 📈 Leaderboard using `localStorage`
- ✅ Word checking and scoring system
- 🔊 Sound effects for actions and feedback
- 🏆 Completion modal with Play Again and Exit options
- 🎯 Track of correctly guessed words
- 🔐 Logout and session handling

## 🧩 How to Play

1. Unscramble the jumbled word using the hint provided.
2. Type the correct word and press **Enter** or click **Check**.
3. Each correct answer adds 10 points to your score.
4. A wrong answer or timeout deducts 5 points.
5. Complete all words to win!
